# FileDesk

Gerenciador de arquivos Android independente, inspirado no Explorador de Arquivos do Windows 11 e otimizado para tablet, teclado, mouse e toque.

## Versão inicial
Navegação por pastas, pesquisa, abrir arquivos, criar pasta, renomear, excluir, histórico de navegação, acesso persistente pelo Storage Access Framework e modo claro/escuro.

Package: `com.simulagamer.filedesk`
